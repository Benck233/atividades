01

Pseudoelementos

Estilize os elementos abaixo usando apenas CSS, sem modificar o HTML:

  1. Use ::before para colocar o emoji 📌 antes de cada item da lista .lista-exercicio.
  2. Use ::after para adicionar o texto "(novo!)" com cor verde após o link .link-novo.
  3. Use ::first-letter para estilizar a primeira letra do parágrafo .texto-capitular: tamanho 3em, cor roxa, flutuando à esquerda.
  4. Use ::placeholder para deixar o placeholder do input em cor laranja e itálico.
  5. Use ::selection para que ao selecionar o texto do parágrafo .selecionar-me, o fundo fique amarelo e a cor do texto fique preta.
  • Aprender CSS é essencial
  • Pseudoelementos são poderosos
  • Não precisa alterar o HTML

Ver documentação

Pseudoelementos permitem criar efeitos visuais avançados sem adicionar elementos extras ao HTML. Eles são selecionados com dois dois-pontos (::) e funcionam como se fossem elementos "fantasmas" dentro do DOM.

02

Fontes e Tipografia

Configure as fontes e propriedades tipográficas dos elementos abaixo:

  1. Importe a fonte Merriweather do Google Fonts (com pesos 400 e 700) adicionando a tag <link> no <head> deste HTML.
  2. Aplique font-family: 'Merriweather', serif ao título .titulo-fontes.
  3. Faça o parágrafo .paragrafo-fontes ter: font-size: 1.1rem, line-height: 1.8 e text-align: justify.
  4. No elemento .destaque-fonte, aplique font-weight: 700, letter-spacing: 3px e text-transform: uppercase.
  5. Remova o sublinhado do link .link-limpo e mude sua cor para #2b6cb0. Ao passar o mouse (:hover), adicione sublinhado novamente.

Tipografia no Design Web

A tipografia é um dos elementos mais importantes do design web. A escolha da fonte certa pode melhorar dramaticamente a legibilidade e a experiência do usuário. Fontes serifadas passam uma sensação de tradição e confiança, enquanto fontes sem serifa tendem a parecer mais modernas e limpas.

03

Medidas e Unidades

Aplique as unidades de medida corretas nos elementos abaixo:

  1. Faça a .caixa-fixa ter width: 300px e height: 150px, com fundo azul claro.
  2. Faça a .caixa-relativa ter width: 80% (do pai) e height: 100px, com fundo verde claro. Redimensione a janela para ver a diferença.
  3. Faça a .caixa-viewport ter width: 60vw e height: 20vh, com fundo roxo claro. Veja como se adapta à janela.
  4. Aplique font-size: 1.25rem ao parágrafo .texto-rem e font-size: 1.25em ao parágrafo .texto-em (que está dentro de um pai com font-size: 20px). Observe a diferença.
  5. Faça o .input-ch ter exatamente width: 14ch (largura de 14 caracteres "0").

04

Cores

Aplique cores usando os diferentes formatos aprendidos:

  1. Pinte o .bloco-named com a cor nomeada steelblue (texto branco).
  2. Pinte o .bloco-hex com a cor #e53e3e (texto branco).
  3. Pinte o .bloco-rgb com rgb(56, 161, 105) (texto branco).
  4. Pinte o .bloco-rgba com rgba(128, 90, 213, 0.5) sobre um fundo listrado (já estilizado). O bloco deve ser semi-transparente.
  5. Pinte o .bloco-hsl com hsl(30, 90%, 50%) (texto branco).
  6. Defina variáveis CSS no :root para --minha-cor-primaria e --minha-cor-fundo e use-as no .bloco-variavel.

Desafio Extra — Cartão de Perfil

Usando tudo que foi aprendido, estilize o cartão de perfil abaixo com pelo menos:

  1. Uma fonte do Google Fonts para o nome.
