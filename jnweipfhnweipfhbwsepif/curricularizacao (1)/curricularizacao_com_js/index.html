Sobre o Projeto

Seja bem-vindo ao nosso Portal de Segurança da Informação. Este site foi desenvolvido como um projeto de curricularização, servindo como uma plataforma interativa para disponibilizar digitalmente as cartilhas de boas práticas criadas pelos alunos de WebLab.

Navegue pelo menu para aprender a se proteger contra ameaças virtuais e utilize nossa ferramenta exclusiva de geração de senhas seguras.

Conteúdos Disponíveis

Cartilha 1: Engenharia Social

Descubra como os criminosos utilizam a manipulação psicológica para roubar dados e como identificar e-mails e mensagens falsas (Phishing).

Cartilha 2: Vulnerabilidades Digitais

Aprenda a reconhecer as principais brechas em sistemas, a importância das atualizações de software e como blindar seus dispositivos pessoais.
